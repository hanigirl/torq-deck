Tips

  1. 01 An agent must have at least one of these traits: autonomy, a loop, judgment, or memory.
  2. 02 One cognitive task only.
  3. 03 Each agent passes to the next only what's needed — to improve performance and cost.
  4. 04 Always tag what's grounded vs. a hypothesis or conclusion — to keep the process transparent.
  5. 05 Add a fresh-eyes agent — one carrying none of its own assumptions, so it comes to the judgment clean.
